# 公开副本脱敏说明

公开仓库使用示例地址替换固定运维地址和两个试点桌面 ID；不会在这里列出原值。`source-provenance.json` 给出脱敏前后摘要与文件列表。

- 运维公网地址替换为 RFC 文档示例段 `203.0.113.20`。
- Mac/试点/监测的 Tailscale IPv4 替换为 `100.64.0.10/.11/.12/.20` 示例；这些不是实际可用地址。
- 临时三轮验收工具 `PILOTS` 两个固定 desktop_id 替换为示例 ID，必须人工审核后再用；该工具不是迁移主流程。
- `windows/install-watchdog.ps1` 默认 MacAddress 改为示例；使用时显式指定当前 Mac 地址。
- 对应文档与测试中相同字符串同步替换；没有改变认证、互斥、续期、释放和转发逻辑。

数据库、完整实际配置、临时安装命令、截图、日志、证书、私钥、Token 和许可证均没有进入公开仓库。历史文档中的试点显示名仅保留为流程标签，不代表当前目录或在线状态。

完全逐字的正式用户部署另存于本地私密快照，不通过公开仓库传播。代码摘要用于确认来源，不意味着能够从摘要恢复秘密。
